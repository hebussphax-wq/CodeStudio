# Demo-Aufgabe (erster Lauf)

Lege im Workspace eine Datei `hello.py` an (oder erweitere sie), die eine Funktion `greet(name: str) -> str` enthält.

Verhalten:
- Rückgabe genau `Hallo, {name}!`
- Wenn `name` leer oder nur Whitespace ist: `Hallo!`

Akzeptanz:
- `greet("Toby")` liefert `Hallo, Toby!`
- `greet("  ")` liefert `Hallo!`

Hinweis: erst `python studio.py --doctor`, dann diesen Auftrag mit `--dry-run` ansehen.
